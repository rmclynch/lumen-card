# Changelog

## 0.7.0

- New **Energy** view for solar and home batteries: sun, battery, house and grid, with moving dots showing which way the power flows. Opens from an **Energy** button on the rail, or the small sun at the top of big screens.
- Finds the sensors by itself (built around Sigenergy Local Modbus); a new `energy:` option lets you name them.
- The built-in "How to use Lumen" guide and the README now explain `?kiosk` for wall screens and tablets (was 0.6.6, never released on its own).

## 0.6.5

- Hides settings switches (valve locks, identify, window detection, hub modes and similar) from room views, for any brand.
- README leads with installing from the Marketplace.

## 0.6.3

- First public release.
